# 互动式源码讲解提示词设计

## 目标

让 Codex 和 Claude 在用户请求讲解、学习、原理或源码分析时，默认采用真正的多轮互动教学，而不是一次输出完整讲义。

## 设计

- 在根 `AGENTS.md` 中把模糊的“对话式讲解”改成可检查的强制协议。
- 每轮只讲一个最小子概念，正文不超过 12 行，代码不超过 15 行。
- 每轮结尾只提出一个理解检查问题，随后停止；用户回答前不得进入下一概念。
- 首轮不倾倒完整答案，也不一次列出多个章节的详细内容。
- 用户明确要求“一次讲完”“完整梳理”或“写成文档”时退出互动模式。
- 在根 `CLAUDE.md` 中保留相同协议，避免 Claude 只读取指针文件而漏掉规则；其余项目说明仍由 `AGENTS.md` 维护。

## 验证

- 检查两个入口文件都包含相同的触发条件、单轮限制、停止条件和退出条件。
- 检查 Markdown 结构与现有文档兼容。
- 检查修改范围只包含提示词和本设计记录。
