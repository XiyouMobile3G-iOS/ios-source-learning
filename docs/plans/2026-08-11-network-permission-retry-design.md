# 更新检查网络权限重试设计

## 背景

`check-updates.sh` 在 agent 沙箱中可能无法访问网络或本机回环代理，并以退出码 `2` 报告检查失败。相同脚本在获得网络权限后可以正常访问远端，因此不应立即退回本地版本，也不应让 agent 绕过脚本手动运行 Git 更新命令。

## 设计

在根目录 `AGENTS.md` 的更新检查流程中明确两阶段处理：首次检查返回退出码 `2` 时，agent 必须申请网络权限并使用原参数重跑一次 `check-updates.sh`。只有重跑仍返回 `2` 时，才声明基于本地版本回答。

该规则只改变 agent 的执行流程，不改变脚本实现、源码版本或更新策略。实际更新仍统一使用 `update-sources.sh`。

## 验证

检查 `AGENTS.md` 同时包含网络权限重跑、仅重试一次、二次失败后使用本地版本，以及禁止手动 Git 更新四项约束。
