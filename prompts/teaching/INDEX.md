# 教学提示词索引

本文件只负责选择需要加载的教学提示词，不存放具体讲解协议。

## 加载规则

1. 用户未指定教学方法或风格时，同时加载下面标记为「默认」的教学方法与默认表达风格。
2. 用户明确指定的方法、风格或预设已在本索引注册时，优先使用其指定项替换对应默认项。
3. 用户明确要求「不要面试版」「只讲原理」或表达等价意图时，只加载默认教学方法，不加载默认表达风格。
4. 组合加载时，先读取方法，再读取风格：方法控制教学节奏，风格控制表达方式及其明确声明的局部覆盖。
5. 只读取当前选中的提示词文件；不要扫描或一次性读取 `prompts/teaching/` 下的全部文件。
6. 用户指定的项目尚未注册时，简短说明它不可用，然后回退到默认教学方法与默认表达风格。

## 扩展约定

- 新增教学方法：放入 `methods/`，并在「当前可用教学方法」中注册。
- 新增表达风格：放入 `styles/`，在「当前可用表达风格」中注册，并标明默认或选择条件。
- 新增完整预设：有实际内容时再创建 `profiles/`，预设可以组合一种方法与一种风格。
- 新增或调整选项时只修改本索引；根 `AGENTS.md` 与 `CLAUDE.md` 保持稳定。
